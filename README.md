# scrollback.archangelic.space

The website for Scrollback: its privacy policy, support and accessibility pages, which the App Store listing links to.

## Edit the site

Edit the HTML files and `style.css`, then push to `main`. GitHub Pages publishes the site in about a minute.

## Change the privacy policy

Update `privacy.html` whenever the app starts sending data somewhere new, change the date at the top, and keep the
App Store Connect privacy answers to match.
